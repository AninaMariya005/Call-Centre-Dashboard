# Call-Centre-Dashboard
This dashboard summarizes call centre performance, showing key metrics like calls, revenue, duration, and customer ratings, along with trends, agent performance, and location-based insights to support better decision-making.

# Questions (KPIs)
  - What is the total number of calls, revenue generated, and average rating?
  - How do call volumes vary across months?
  - Which days have the highest number of calls?
  - How do different locations perform in terms of calls and revenue?
  - Which representatives handle the most calls?
  - What is the distribution of customer ratings?
  - What are the busiest periods in the call centre?

# Process
  - Checked dataset for missing values and inconsistencies
  - Cleaned and formatted data for accurate analysis
  - Created calculated measures for KPIs (calls, revenue, ratings)
  - Built visuals to analyze trends, agent performance, and location insights
  - Combined all visuals into a single interactive dashboard
  - Added filters/slicers for dynamic data exploration

# Project Insights
  - Call volumes show fluctuations across months with noticeable peak periods
  - Certain days (mid-week) receive higher call traffic
  - Some representatives consistently handle more calls than others
  - Locations like Cincinnati, Cleveland, and Columbus show varied performance
  - Customer ratings are mostly concentrated in higher ranges, indicating good satisfaction
  - A large portion of calls are successfully handled

# Final Conclusion
To improve call centre performance, focus should be placed on optimizing staffing during peak days and hours, supporting high-performing representatives, and improving performance in lower-performing locations. Additionally, maintaining high customer satisfaction levels through quality service can further enhance overall efficiency and business outcomes.
